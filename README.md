### ⚠️ PROYECTO CON FINES DE APRENDIZAJE

---

Este proyecto está basado en el código original de Evan You para **Vue.js** en
su versión 0.6.0.

#### Descripción

**_Insolida_** nace como una forma de aprender en profundidad cómo funcionan los
frameworks y bibliotecas web modernas creando una versión propia desde cero (así
como lo hizo Evan You en el 2013) tomando como referencia las versiones
tempranas del código original de Vue.js. Todos mis avances se irán subiendo a
este repositorio.

#### 📌 Objetivos principales del proyecto

- ✔️ Mejorar conocimientos en Typescript y aprender más.

- ✔️ Aprender a usar el método estático Object.defineProperty().

- ✔️ Crear una versión mínima de framework funcional.

- ✔️ Aprender cómo funciona la reactividad, virtual DOM, qué es diffing y demás.

- ✔️ Divertirme: todo esto lo hago por pura entretención y creo que tengo suerte
  de poder decirlo.
